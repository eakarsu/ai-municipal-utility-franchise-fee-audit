# Municipal Utility Franchise Fee Audit

Reconstruct utility gross receipts and recover underpaid municipal franchise fees across territories and customer classes.

**Primary buyer:** Cities, counties, and public finance departments. **Evidence:** franchise agreements, service addresses, customer classes, gross receipts, exclusions, rates, returns, payments, and audits.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Franchise agreement library
- Territory boundary mapping
- Service address matching
- Customer class mapping
- Gross receipt ingestion
- Excluded revenue validation
- Rate tier calculation
- Bad debt treatment
- Affiliate revenue review
- Return period reconciliation
- Underpayment calculation
- Utility audit request
- Assessment notice workflow
- Cash collection tracking
- Territory utility analytics

Run `./start.sh`, then open <http://127.0.0.1:4692>. API: `5692`.
